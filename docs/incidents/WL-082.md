# WL-082: Analysis failed with "error_during_execution" and "Terminate batch job (Y/N)?"

- **Work-log item:** [WL-082](../work-log.md)
- **Date:** 2026-10-23
- **Severity:** medium (one analysis lost; plan usage for an aborted call; a raw JSON dump in the chat)

## Context

Sheryar ran a Full analysis on BINANCE:BTWUSDT.P 15m with the Claude subscription provider while Claude was editing `backend/app` for WL-069 to WL-073.

## Symptom

> Error: AI error: Claude Code error: ... "is_error":true,"num_turns":2,"subtype":"error_during_execution","errors":["[ede_diagnostic] result_type=user last_content_type=n/a stop_reason=null"],"type":"result","duration_ms":270 ... Terminate batch job (Y/N)?

## Diagnosis

The same `claude -p` arguments with a tiny prompt worked twice (3.3 s, through `claude.CMD` and through `claude.exe`), so the CLI, the flags and the login were fine. `claude` on PATH is npm's `claude.CMD`, a cmd.exe batch wrapper around `bin/claude.exe`; cmd.exe prints "Terminate batch job (Y/N)?" only when a Ctrl+C or Ctrl+Break reaches the batch, and the CLI result says it stopped after 270 ms in the middle of a turn. `start.ps1` starts uvicorn with `--reload`, which restarts the worker whenever a file under `backend/app` changes; those files were being edited at the time, so the restart interrupted the running CLI. The child shared the server's console process group, so the interrupt reached it.

## Fix

- `config.claude_cli` resolves npm's `.CMD` wrapper to the `claude.exe` beside it: no cmd.exe, no batch prompt in the output.
- The CLI runs with `CREATE_NEW_PROCESS_GROUP`, so a Ctrl+C in the server window does not abort it.
- `ai.claude_code_error` turns a failed result into one sentence (interrupted, out of turns, not logged in, or a short detail) instead of the raw JSON; `_cli_json` reads the result object even with a stray line after it.
- Checked with one real tiny call through the app path: "OK" in 4.4 s.

## Prevention / follow-ups

- Tests in `backend/tests/test_claude_code_cli.py` (wrapper resolution, the screenshot's output, process group, stray line).
- A restart during a call still loses that call; the message now says so. While Claude edits backend code, the `--reload` server restarts: avoid running analyses during edits, or run without `--reload`.
